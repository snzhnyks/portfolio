# Yuliana Yemelianenko — Hospitality Growth Studio

An English-first static portfolio for hospitality social media strategy and paid social. It presents four case studies:

- Isla Palenque
- Finca Lérida
- Mana Earthly Paradise
- Suenyo Eco Retreat

## Local preview

Open `index.html` in a modern browser. The site is dependency-free and uses plain HTML, CSS and JavaScript.

## GitHub Pages

For the site to work correctly, publish `index.html`, `styles.css`, `script.js` and the complete `assets/` directory to the repository root. The project is designed for GitHub Pages at `https://snzhnyks.github.io/portfolio/`.

## Media

The `assets/` directory contains the project visuals, profile grids, post covers and strategy decks used throughout the case studies. Keep the directory structure unchanged because paths are referenced directly from the site source.
